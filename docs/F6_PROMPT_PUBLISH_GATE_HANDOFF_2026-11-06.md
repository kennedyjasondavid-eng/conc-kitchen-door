# F6 prompt save while delivery is pending

Frozen actual-browser gate `tests/browser/menu_flow_f6_prompt_publish.mjs`, SHA256 `a1b4b91ea78690499cedab9db34578dec35e39c4df21fa8b639a18292e277ed8`. This separate eight-case supplement preserves all earlier delivery/recovery gates. It directly tests the reviewed requirement that urgent edits use the existing prompt flush and that delivery checking not introduce a delay for each save.

Baseline product `21c8550e164efda629cb2fc2e107b99f418e4c8632fa02ffbf5011f8d2bc43e2`: **8 checks, 4 pass and 4 fail**. Log `%TEMP%/door-ci-audit-20261106/f6-prompt-publish-red.log`. A commits through the real publisher and its actual anonymous Pages response is held. B then edits the real menu/outbox and calls the same real publisher in the same tab. Without advancing the product clock or releasing A's response, A does not return and B cannot commit/acknowledge. The visible status still says “Sending” although A is already committed. After release, both writes finish; delayed A proof cannot certify B, and no extra write/runtime failure occurs.

The source cause is `await doorDeliveryVerify(false)` inside the serialized content-publish queue after durable commit recording and local acknowledgement. A slow public request can occupy that queue for eight seconds; a later slow EXPO-proof request can extend it again. The small bounded verification budget does not remove this newly introduced dependency between delivery observation and a later content edit.

Required repair: once commit/debt/acknowledgement are safely recorded, render truthful pending state and start independently guarded delivery observation without keeping the content-publish queue occupied. Existing native verification locks, attempt limits, stale-result guards and newer-intent preservation must remain. This is not permission to detach Git/CAS/receipt durability or claim delivery early. The gate holds actual transport only, invokes no publisher substitute, and uses a bounded driver scheduling window while leaving product time fixed.
